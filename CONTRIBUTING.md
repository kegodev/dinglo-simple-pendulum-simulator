# Contributing

Contributions that improve the educational accuracy and usability of the Dinglo Simple Pendulum Simulator are welcome.

## Useful contributions

- Reproducible bug reports
- Physics-model validation with equations or references
- Accessibility and responsive-layout improvements
- Documentation corrections and experiment ideas
- Small performance improvements

Open an issue first, keep pull requests focused, explain how the change was tested, and include screenshots for visible interface changes. Do not add copyrighted assets or personal data.
